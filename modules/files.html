GET /api/v1/files/raw Proxy binario: entrega el archivo inline (Content-Disposition: inline) resolviendo el objeto SOLO a traves de los hooks de storage del core. - local → StreamResponse inline si file_exists (404 si no) - google → download_app_files() → StreamResponse (404 si null) - custom → app_filter_get_file_content en try/catch → bytes inline; si vacio, resuelve la URL firmada del provider y hace un probe server-side (solo http/https, 30s, SSL verify): 200 → stream | 400 → scheme invalido | 404 | 410 | 502 | 503 No depende de presigned URLs: util cuando el link firmado expiro (TTL de DO Spaces: +7 dias).
